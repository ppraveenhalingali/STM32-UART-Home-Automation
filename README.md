# STM32 UART Home Automation System

## Description
A UART controlled home automation system built using STM32F103C8T6.

The user sends commands through Proteus Virtual Terminal and STM32 controls multiple peripherals.

## Features

- UART communication
- LED control
- Buzzer control
- DC motor control
- Command based control

## Hardware

- STM32F103C8T6
- Virtual Terminal
- LEDs
- Buzzer
- DC Motor
- BC547 transistor

## UART Pins

TX:
PA9

RX:
PA10


## Commands

LED1 ON
LED1 OFF

LED2 ON
LED2 OFF

BUZZER ON
BUZZER OFF

MOTOR ON
MOTOR OFF

STATUS


## Tools Used

- Keil uVision
- Proteus
- STM32 Standard Peripheral Library
